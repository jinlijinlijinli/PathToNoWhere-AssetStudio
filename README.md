# PathToNoWhere AssetStudio

[English](README.en.md) | 简体中文

《无期迷途》国服 Android 资源工具合集。提供 Unity 资源浏览与导出、视频下载、游戏文本导出和 Live2D 提取。非官方项目。

本教程以 **2026-11-11 更新（客户端 2.5.2，资源版本 10）** 为例。已有从手机或模拟器导出的游戏数据时，**没有 APK 也可以使用四套工具**；可提取的内容取决于你的本地资源和媒体清单。

## 下载和安装

前往 [GitHub Releases](https://github.com/jinlijinlijinli/PathToNoWhere-AssetStudio/releases)，选择包含 11 月 11 日适配的发布包。下载后完整解压，再双击对应 EXE。请保留旁边的 DLL、`_internal` 和其他子目录。GitHub 自动生成的源码 ZIP 不是可运行版。

| 工具 | 启动文件 | 没有 APK 时选什么 |
| --- | --- | --- |
| AssetStudio PtN 修复版 | `AssetStudioModGUI-PtN.exe` | 包含 `fs`、`fschunk` 等目录的游戏资源根目录 |
| 视频下载工具 | `无期迷途视频下载工具.exe` | 游戏目录中的 `fs/res_media.json` |
| 文本提取工具 | `无期迷途文本提取工具.exe` | 包含 `fs` 和 `fstier1` 的游戏资源根目录，APK 栏留空 |
| Live2D 提取工具 | `无期迷途Live2D提取工具.exe` | 包含 `fs`、`fschunk` 等目录的游戏资源根目录 |

适用于 Windows 10/11 64 位。AssetStudio 主程序需要 **.NET 6 Desktop Runtime（x64）**，普通 .NET Runtime 不够。其余独立工具随附运行环境。

## 准备游戏文件

1. 在游戏中下载所需资源，再从手机或模拟器复制游戏数据到电脑。
2. 资源根目录通常是 `Android/data/com.zy.wqmt.cn/files`。如果你复制后改了目录名，直接选择改名后的目录。关键是打开它就能看到 `fs`、`fstier1`、`fschunk` 等子目录。
3. 保留原始目录结构。特别是导出文本时，**不要只复制 `fs`**，新版简体中文词库在 `fstier1/blocks`。建议把提取结果保存到游戏目录之外。

APK 是可选补充。只有部分资源时，可以补充同版本 APK；单独的 APK 可能不含热更新和按需下载内容。

## 四套工具怎么用

### AssetStudio：浏览和导出 Unity 资源

打开修复版 → **File → Load folder** → 选游戏资源根目录 → 等待加载 → 在资源列表里筛选类型、搜索并导出。只查单个已知资源包时，可用 **File → Load file**。

若弹出 `Invalid chunk header`，先确认使用的是 11 月 11 日修复版，并保留随包的 `PtnChunkSupport.dll`。新版 `fschunk` 会在资源条目间加入 64 字节对齐填充，旧版会误判为坏包。

### 视频下载：没有 APK，直接选媒体清单

点击 **「选择 APK / 清单文件」** → 选 `游戏目录/fs/res_media.json` → 选保存目录 → **「开始下载」**。这个 JSON 是视频清单，下载需要联网。

如果大量出现 404，打开「地址设置」，检查默认路径是否还是 **2.4**。应填写与当前清单匹配的媒体资源根地址，可从自己的游戏播放日志识别，详见发布包的《进阶提取教程》。**不要直接把客户端版本号 2.5.2 当作 CDN 路径**。清单也不一定包含历史上全部视频。

### 文本提取：新版不需要补 APK

1. 打开 11 月 11 日版文本工具，游戏目录选择同时包含 `fs`、`fstier1` 的根目录。**APK 栏留空**。
2. 选保存目录，再选择导出范围：
   - **仅剧情对话**：导出所有已识别的章节和对话分卷。
   - **按章节选择**：先点击「读取 / 刷新章节」，搜索、勾选所需章节，再导出。
   - **所有游戏文本（推荐）**：另含审查、情绪检测、监管终端及其他配置和 Unity 文本。额外扫描需要时间和磁盘空间。
3. 点击「开始导出」。全量结果先打开「全部文本阅读版」；用「文本索引.csv」搜索配置文本。「审查个人剧情」可在「审查 / 逐条阅读」查找，部分文件用数字 ID 命名。

如果旧工具提示缺少 `configtexts.lua`，先换新版，再确认 `fstier1/blocks` 已复制完整。新版支持 DPK1/DBC1 文本包；用本次游戏目录、不提供 APK，已验证读取 **606,920 个文本 ID**并导出 **63 份章节**。这些是本次验证的数量，不是其他版本的固定值。

剧情保留原始对话步骤、说话人、选项和分支；不会替玩家选路线。少数未解析字段见提取报告，部分解析结果不应视为完整配置。

### Live2D：按角色提取

打开独立的 `无期迷途Live2D提取工具.exe`，或从修复版 AssetStudio 的「Live2D 工具」菜单进入 → 选游戏资源根目录和输出目录 → **「读取角色列表」** → 搜索、勾选 → **「提取所选角色」**。

首次读取会整理资源，可能较慢。「工作数据」是缓存，「提取好的模型」是结果。若旧版解包中途报过 `Invalid chunk header`，换用 **内置解包组件也已更新的 Live2D 版本**，并选择新的空输出目录。只更新 AssetStudio 主程序不能修复旧 Live2D 解包组件。

## 常见问题

- **EXE 打不开**：完整解压 ZIP；不要把 EXE 单独移走。AssetStudio 另需检查 .NET 6 Desktop Runtime（x64）。
- **找不到某项资源**：检查游戏是否已下载对应资源，以及目录是否复制完整。不要混用不同版本的文件。
- **找不到独立 Animator**：模型、AnimationClip 和 Animator 是不同对象。有些包只提供模型、骨架、动作及自定义状态数据，不一定有同名 AnimatorController。
- **反馈问题**：附上工具版本、游戏版本、所选目录结构和脱敏报错。不要公开账号、设备信息或整份游戏数据。

## 源码和许可

`src/text` 存放文本工具源码，`src/components` 存放可提供的扫描和解包组件。部分旧版 GUI 仅提供发布二进制。第三方组件沿用原许可，见 `licenses` 和发布包内说明。游戏资源版权归相关权利人；发布包不包含游戏 APK、模型、贴图、剧情或视频。
