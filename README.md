
# PathToNoWhere AssetStudio

[English](README.en.md) | 简体中文

面向《无期迷途》国服 Android 资源的 Windows 工具合集：AssetStudio PtN 修复版、视频下载、全游戏文本导出及 Live2D 提取与处理。非官方项目，与游戏官方无关联。

## 下载与安装

前往本仓库 **Releases**，下载需要的 ZIP，完整解压后启动 EXE。不要只复制 EXE，也不要在压缩包内运行。仅支持 Windows 10/11 64 位。仓库源码 ZIP 不等于可运行发布包。

AssetStudio 主程序需要 .NET 6 Desktop Runtime（Windows x64）。其余独立组件随附运行环境。

## 准备游戏文件

使用自己的同版本 APK 和已下载的游戏数据。资源目录通常是 `Android/data/com.zy.wqmt.cn/files`，其中包含 `fs`、`fsclassify`、`fschunk` 等目录。工具不附带 APK、模型、贴图、剧情或视频。仅 APK 可能缺少热更新和按需下载内容。

## 四套工具怎么用

### AssetStudio

启动主程序，通过 File 菜单加载文件或文件夹，等待解析，再筛选需要的资源并导出。Live2D 可通过“Live2D 工具”菜单打开集成工具。请把输出保存到独立目录。

### 视频下载

选择 APK 或 `res_media.json` → 选择保存目录 → 开始下载。下载器需要网络；版本变化可能导致默认 CDN 路径失效，可在地址设置中修改或从自己的播放日志识别。完整日志获取步骤见包内“进阶提取教程.md”；分享日志前删除设备、账号和连接信息。不保证媒体清单覆盖历史全部视频。

### 所有游戏文本

选择游戏数据目录 → 补充同版本 APK → 选择“所有游戏文本（推荐）” → 开始导出。输出中的“全部文本阅读版”含审查、情绪检测、监管终端和其他文本分类，“文本索引.csv”可搜索配置文本。“审查/逐条阅读”包含关联的个人剧情对话、选项和日记，文件可能按 ID 命名。仅要剧情时选择剧情模式；按章节导出需先读取章节、搜索并勾选。

原始配置、字符串常量和 Unity 文本也会保留。部分配置尚未完全解码，以报告为准，不承诺未下载或服务器端文本。审查分支保留原始顺序与跳转，不自动选定剧情路线。

### Live2D

选择能看到 `fs` 等目录的游戏文件夹 → 选择输出 → 读取角色列表 → 勾选角色 → 提取所选角色；也可提取全部。首次整理较慢。处理工具用于后续处理，详细说明见包内“先看这里.txt”。本项目不承诺导出结果兼容所有第三方播放器。

## 常见问题

- 找不到资源：确认游戏已完成资源下载，APK 与数据版本匹配。
- 缺少组件：重新完整解压，保留 `_internal` 和 DLL；AssetStudio 检查 .NET 6 Desktop Runtime。
- 文本缺失：检查提取错误、未解析 ID 和整理报告；不要将 partial 配置视为完整结果。
- 反馈问题：请提供工具版本、操作步骤和脱敏错误信息，不要上传账号信息、私人日志或整份游戏数据。

## 源码与许可

`src/text` 为本次文本工具源码，`src/components` 为工作区中可获得的自定义扫描、解包等组件。部分旧版 GUI 的源码未在当前工作区找到，其二进制仅在 Releases 提供；本仓库不是所有组件均可完整重建的上游源码镜像。

AssetStudio 和其他第三方组件保留原有许可，见 `licenses` 及各发布包。Live2D/Cubism 相关组件遵守其原始条款，不因本仓库而改变授权；使用前检查包内第三方许可。游戏资源版权归相关权利人。仓库不提供游戏资源或绕过账号访问限制的功能。
