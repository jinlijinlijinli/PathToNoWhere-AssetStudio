# 无期迷途文本提取工具

Windows 10/11 64 位图形工具。完整解压后双击 `无期迷途文本提取工具.exe` 使用，不需要安装 Python 或 .NET，也不需要输入命令。

## 本次更新：所有游戏文本

默认选择“所有游戏文本（推荐）”。导出后优先打开“全部文本阅读版”：

- **审查 / 逐条阅读**：每条审查独立 TXT，包含记录、日记、原始步骤，并展开命中的对话 ID，保留选项和跳转。
- **情绪检测 / 逐条阅读**：按角色 ID 输出描述、提问、全部选项及对应回答。
- **监管终端 / 逐条阅读**：按事件 ID 输出事件名、描述、对话、选项、情绪及原始上下文。
- **其他游戏文本、剧情与对话**：所有已解码配置表均生成 TXT，不只筛选剧情关键词。
- **文本索引.csv**：按分类、来源表、记录 ID、字段路径列出全部配置字符串，可用表格软件搜索。

角色名无法可靠确定时保留 ID；原始表和字符串池仍一同导出。部分表未完全解码的限制仍适用，不能保证未下载或服务器端文本。

## 最简单的用法：不用 APK

1. 完整解压发布包，双击 `无期迷途文本提取工具.exe`。
2. **选择游戏数据目录**：选择打开后能看到 `fs` 和 `fstier1` 的根目录，例如从手机或模拟器复制出来的 `Android/data/com.zy.wqmt.cn/files`。不要只选 `fs` 子目录或单个资源包；新版简体中文文本在 `fstier1/blocks`。
3. **APK 栏留空**。本次验证的 11 月 11 日国服 Android 版（客户端 2.5.2、资源版本 10）可以直接从本地游戏目录提取。
4. 选择保存位置和导出范围，点击「开始导出」。建议把输出放在游戏目录之外。

APK 仅用作可选补充。如果某些资源没有复制完整，可以先补齐同一版本的游戏数据，或补充同版本 APK。单独的 APK 可能缺少热更新和按需下载内容。

## 三种导出方式

### 全部剧情

适合想一次保存剧情的使用者。输出包含：

- 按游戏回顾目录整理的章节 TXT；
- 回顾目录之外也可能包含的全部对话 ID 分卷；
- 已识别的剧情、故事、对话、聊天等相关配置表；
- 章节目录与缺失/未解析项报告。

正文保留说话人、选项、FemaleContent 分支和 Jump 信息，不擅自选定一条剧情路线。部分对话 ID 是开发测试记录，属于原始资源内容。

### 按章节选择

1. 点击“读取 / 刷新章节”，等待首次解析完成。
2. 输入章节名称或回顾 ID 搜索。
3. 点击列表行勾选需要的章节。
4. 选择“按章节选择”，点击“开始导出”。

“全选当前列表”只选择当前搜索结果。清空搜索保留已勾选项；“清空选择”会取消所有勾选。导出结果只包含选中的章节、目录与报告。

同名章节可能是不同的回顾记录，请结合回顾 ID 和顺序区分。

### 所有文本资源

除剧情外，还导出所提供文件中已支持格式的：

- 中文文本 ID 与原文对照；
- 去重的配置文本池，包括角色、技能、物品等文案；
- 界面和系统文本键值；
- 所有已解析脚本主函数及嵌套函数中的可读 UTF-8 字符串；
- 原始脚本字节码；
- 已支持的本地化配置表，以及未完全解码的部分记录；
- Unity TextAsset 原始数据及可读文本；
- Unity 对象中的中文字符串和界面文字字段，包括安装包内置资源。

此模式会解压扫描大量 Unity 资源，耗时和磁盘占用高于剧情模式。工具会显示扫描进度；提取结果及缓存可能占用数 GB，具体取决于输入文件。

## 从哪里打开结果

导出完成后点击“打开导出结果”。每次导出都新建带时间的文件夹，不覆盖之前的正式导出目录。

- `剧情按章节/`：优先从这里阅读。
- `剧情目录.csv`：章节名称及对应文件。
- `从这里开始.txt`：本次结果的阅读说明。
- `导出摘要.json`：本次模式、范围与缺失/错误数量。
- `提取错误.json`、`剧情整理报告.json`：尚未解析的配置表或缺失的对话引用。

所有文字文件使用 UTF-8。游戏原有的字号、颜色等富文本标签和替换占位符会保留。`.jsonl` 表示每行一个 JSON 对象，`.luac` 与 `.bytes` 可能是二进制，不能当作普通文本阅读。

文本 ID 使用字符串保存。请避免直接用 Excel 将它们转换成数字，否则可能丢失大整数精度。

## 输入与支持范围

支持新版 DPK1/DBC1 文本包、明文及旧异或文本块和已适配的 PtN Unity 资源。用 11 月 11 日版的本地目录、不提供 APK，已验证读取 **606,920 个中文文本 ID**、导出 **63 份回顾章节**。数量以实际输入为准。

“所有剧情 / 所有文本”指所提供文件中可识别的内容。它不包括未下载、服务器端或历史版本资源。新版系统文字以原始哈希为键。少数配置字段未完全解析时，请查看提取报告，不要将部分结果当成完整配置。

## 缓存、停止和排查

- 首次读取会在保存位置生成“工作缓存”，供章节列表和后续导出复用。
- 更换输入版本或文件变化后，会使用新的缓存。
- 缓存与正式结果分开。工具关闭后可自行删除“工作缓存”，下次会重新解析。
- 点击“停止”后等待当前解析步骤结束；Unity 扫描子进程也会结束。
- 未完成的解析不会标记为可用缓存；未完成的正式导出目录可能包含部分文件。
- 不建议同时启动多个工具实例并使用同一个保存位置。
- 失败时可点击“查看运行日志”并保存日志，报告内的来源路径只在本地记录。

常见问题：

**找不到 blocks / 缺少 configtexts.lua**：先确认使用 11 月 11 日适配版，并检查所选目录下的 `fs`、`fstier1/blocks` 是否复制完整。APK 不是必填项。

**只选 APK 失败**：确认是包含 `assets/res_manifest` 和 `assets/blocks` 的普通 APK。XAPK/APKS 请先解压，选择正确的资源 APK。

**资源缺失 / 章节比别人少**：确认游戏数据已下载并完整复制；如果额外提供了 APK，确认它与数据版本一致。本工具不联网补下载剧情。

**缺少扫描组件**：完整解压 ZIP；保留 `_internal` 目录，不要只复制 EXE。

**结果有未解析项**：查看导出摘要及错误报告。保留原始输入以便后续适配，不要将 `.partial.jsonl` 当作完整配置表。

## 本地处理与分享

工具本地读取和解码资源，不需要账号登录、ADB 或 root，不执行提取到的游戏脚本，不上传文件或日志。原始输入资源不修改，分片合并在工作目录的副本中进行。

工具发布包不附带游戏资源、个人路径、账号或运行日志。分享工具时发送整个 ZIP；游戏文本的使用与转载请遵守官方规则及相关权利人的要求。

## 技术与组件

界面与编排使用 Python/Tkinter，打包为 Windows 程序；Unity 文本解析使用本工作区的 AssetStudio PtN 修复组件。内置 .NET Runtime 用于运行扫描组件，相关运行时许可随包保留。

源码置于 `源码/`。文本块解码器静态解析常量、字面量表及已知数据数组，不执行游戏脚本函数。正式发布包不包含测试时导出的游戏内容。
